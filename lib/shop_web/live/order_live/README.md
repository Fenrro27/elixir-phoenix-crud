# OrderLive - Order Success & History

## LiveViews
- `Success` - `/orders/:id/success` - Order confirmation page
- `Index` - `/account/orders` - User order history (v2+)
- `Show` - `/account/orders/:id` - Order detail (v2+)

## Features
- Success: order summary, estimated delivery, email notice
- History: paginated, filterable by status
- Detail: items, totals, timeline, tracking (future)
